## 3. Capability — PASS

`capability.led`（vendor-free）：**闭布尔 schema** `{"on": bool}`（契约系统新增 boolean 字段类型——最小扩展）；非布尔/附加键/缺键全拒；契约零 handler/function/url/shell/gpio/pin 字段。

## 4. DeviceCommand — PASS

operation 枚举 + SET_LED；参数闭类型（str/bool，int 拒）；command_id 仍为确定性幂等键（**派生含 operation**——同一上下文同一 id）。

## 5. Firmware changes — PASS

LED_PIN=2（板载，boot 时 fail-safe OFF）；advertisement=TEST_ECHO+SET_LED；SET_LED 严格验证（size==1 + on 键 + bool 型）；执行=digitalWrite(LED_PIN, on)——**唯一 sanctioned 身体动作**；无 SET_GPIO/gpio_set_level（无通用 GPIO 接口）；版本 0.3.0-p19。

## 6. Adapter changes — PASS

action_type→operation **严格白名单映射**（SET_LED→SET_LED，其余→TEST_ECHO）；**修复 P19 发现的真实缺陷**：此前 from_request 未传 operation（默认 TEST_ECHO）——SET_LED 命令从未正确构造，现映射正确且 command_id 同步。

## 7. Protocol / 8. Session changes — PASS

DeviceAck echo 支持 string→boolean；会话门禁照旧（ONLINE+广告通过；unknown/offline/stale/mismatch 拒，send=0 实测）。
