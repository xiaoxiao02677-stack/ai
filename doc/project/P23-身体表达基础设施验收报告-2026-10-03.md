## 1. 实现内容

建立 **AI 状态 → 身体表达** 独立边界（区别于 P13 Action 执行边界）：

```
AI 内部状态（系统事件驱动）
  → ExpressionIntent     （"身体现在应表达什么"）
  → ExpressionPolicy     （闭表：状态→操作映射；LLM 永不直接选操作/GPIO/命令）
  → ExpressionGateway    （表达专用边界，独立可靠性域）
  → LCDExpressionAdapter （body expression 适配器：Mock + 网关通道双模式）
  → DeviceCommand SET_LCD_STATE（P15 现有协议，向后兼容扩展）
  → 现有 codec/session/transport/lifecycle 栈（零第二套）
```

## 2. Expression 状态模型

闭集六态：`IDLE / THINKING / EXECUTING / SUCCESS / ERROR / WAITING`（无情绪/人格状态——P23 是基础设施不是情绪系统）。状态机含显式转移表（自转移=幂等刷新）。

## 3-6. 各组件

- **ExpressionIntent**：state/reason/source/created_at（非 ActionIntent——无 capability/参数自由度）
- **ExpressionPolicy**：闭映射表（默认 1:1 状态→SET_LCD_STATE {state}；敌意映射构造即拒）
- **ExpressionGateway**：express(intent)→policy→adapter→ExpressionResult；observer 记录（观察失败不破坏表达）
- **LCDExpressionAdapter**：mock=True（确定性软件 LCD，明确标注）/mock=False（经 workshop GatewayChannel 下发真实命令+读真实 ACK）
