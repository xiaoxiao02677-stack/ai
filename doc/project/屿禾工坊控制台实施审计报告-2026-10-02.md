## 6. 缺失项（本阶段补齐）

| 缺口 | 说明 |
|---|---|
| **POST /commands** | 规范 §六要求的命令 API 现名 `/led`——补语义别名 + UI 命令进 P18 observer（CREATED→…→REJECTED/ACKED 真实流水） |
